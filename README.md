# catalyticsouls

Research project around Thomas W. Hughes' 2007 SIU Carbondale thesis, *Digital Media Technology, Synergy and Making It in Electronic Dance Music*, the Catalytic Souls crew and Underground Sound festivals it documents, and the Shawnee Salt Petre Cave near Murphysboro, Illinois, followed through to 2026.

- `Tom-Hughes-Thesis.docx` — the source document.
- `research/` — the long-form writeup (`00-WRITEUP-...md`), a primary findings log with URLs, three raw research-agent reports, and raw materials (extracted thesis text, Discogs API dump, recovered Wayback pages and flyers).
- `site/` — a deployable VitePress wiki presenting all of it. See `site/README.md` for local dev and Netlify deployment.

Compiled September 2026.
